# Code of Conduct

This project follows the [Contributor Covenant Code of Conduct v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Summary

- Be respectful and welcoming to all contributors.
- Focus feedback on ideas and skills, not people.
- Assume good intent; ask before escalating.

## Reporting

To report an issue, open a GitHub issue marked **[CONDUCT]** or contact the maintainer directly via GitHub.

Maintainers have the right to remove, edit, or reject contributions that do not align with this Code of Conduct.
